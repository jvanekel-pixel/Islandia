# Code drafts — never compiled, never run

Sixty-four files extracted verbatim from the blueprint (`MANIFEST.json` maps each to its phase).
They are **not part of the build**: this directory is outside `Assets/` and `Packages/` on purpose.

Use them as a detailed sketch. Port file by file into the real project behind tests. Expect
invented or mis-used APIs, features that are described but absent, and wiring that assumed a human
in the Unity Editor. The matching file in `docs/plan/audit/` lists the known defects per draft.
